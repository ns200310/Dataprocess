## Installation

1. Requires PHP 8.5 and Composer installed
2. Please open the terminal and please run ```git clone https://github.com/ns200310/Dataprocess```
3. cd into the directory
4. please run ```composer install```
5. please run ```npm install```
6. please run ```php artisan migrate```
7. Please add the ENV variables
8. please run ```composer run dev```
9. please open http://localhost:8000
10. Please run in a separate terminal in the same directory ```php artisan queue:work```
11. to see the schedules lease run in a separate terminal in the same directory ```php artisan schedule:list```
